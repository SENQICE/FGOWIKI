# FGO Wiki 资源下载器

## 项目简介

这是一个用于从 FGO Wiki 网站下载游戏资源的自动化工具。主要功能包括：

- 批量下载英灵（从者）的游戏资源
- 批量下载概念礼装资源
- 资源分类保存，包括立绘、头像、文字解说等
- 支持断点续传和重复文件跳过
- 文件验证和磁盘空间检查

## 目录结构

```
fgowiki-TR/
├── config.py         # 配置文件
├── scraper.py        # 网页抓取模块
├── downloader.py     # 下载器模块
├── cli.py            # 命令行交互界面
├── main.py           # 主程序入口
├── requirements.txt  # Python依赖
└── README.md         # 使用说明文档
```

## 安装依赖

首先确保已安装 Python 3.7 或更高版本，然后安装依赖：

```bash
cd D:\code-x\fgowiki\fgowiki-TR
pip install -r requirements.txt
```

或者手动安装：

```bash
pip install requests beautifulsoup4 lxml tqdm
```

## 使用方法

### 方式一：交互式界面（推荐）

直接运行程序，会显示中文交互菜单：

```bash
python main.py
```

菜单选项：
- 1. 下载所有英灵资源
- 2. 下载所有概念礼装资源
- 3. 下载所有资源
- 4. 自定义下载范围
- 5. 查看下载统计
- 6. 验证已下载文件
- 7. 查看磁盘空间
- 8. 导出资源列表
- 9. 清理重复文件
- 0. 退出程序

### 方式二：命令行参数

#### 下载所有英灵

```bash
python main.py --servants
```

#### 下载所有概念礼装

```bash
python main.py --ces
```

#### 下载所有资源

```bash
python main.py --all
```

#### 限制下载页数（测试用）

```bash
python main.py --servants --pages 5
```

#### 验证下载的文件

```bash
python main.py --verify
```

#### 调整并发数

```bash
python main.py --all --workers 3
```

#### 安静模式（减少输出）

```bash
python main.py --all -q
```

## 配置说明

编辑 `config.py` 文件可以自定义下载行为：

```python
# 下载根目录
DOWNLOAD_ROOT = "D:/code-x/fgowiki/fgowiki-TR/downloads"

# 并发下载线程数
MAX_WORKERS = 5

# 请求间隔(秒)，避免过于频繁
REQUEST_DELAY = 1.0

# 请求超时时间(秒)
REQUEST_TIMEOUT = 30

# 最大重试次数
MAX_RETRIES = 3
```

1. **网络要求**：需要稳定的网络连接，建议使用代理如果访问受限
2. **磁盘空间**：FGO拥有大量角色，请确保有足够磁盘空间
3. **下载速度**：程序设置了请求间隔以避免对服务器造成压力
4. **版权声明**：下载的资源仅供个人学习研究使用，请遵守网站的使用条款

## 常见问题

### Q: 下载失败怎么办？
A: 程序会自动重试3次。如果持续失败，请检查网络连接或稍后重试。

### Q: 如何只下载特定角色？
A: 可以修改代码中的过滤逻辑，或手动下载特定页面。

### Q: 能否加快下载速度？
A: 可以调整 `config.py` 中的 `MAX_WORKERS` 参数增加并发数，但可能增加服务器负担。

### Q: 下载中断了怎么办？
A: 程序会自动跳过已存在的文件，重新运行即可继续下载。
